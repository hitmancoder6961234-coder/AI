# MASTER PROMPT — BUILD A WORLD-CLASS AI PROJECT BUILDER PLATFORM

## ROLE

Act as a **world-class product architect, UI/UX designer, full-stack engineer, AI systems architect, DevOps engineer, security engineer, QA engineer, and product strategist**.

Your task is to design and build a **production-quality international AI platform** that feels like a combination of:

* AI assistant
* AI software engineer
* AI project manager
* AI designer
* AI researcher
* AI testing engineer
* AI presentation/document creator
* AI deployment platform

The platform must NOT feel like a basic chatbot.

It should feel like:

> **“An entire software company inside one AI platform.”**

The core philosophy is:

> **Describe it → Understand it → Visualize the plan → Approve it → Build it → Test it → Fix it → Preview it → Deploy it.**

The final product should have a premium, futuristic, highly polished interface comparable to leading international AI products.

---

# 1. PRODUCT VISION

Build an AI-powered platform where a user can simply describe an idea in natural language.

Example:

> “I want to build an e-commerce website for selling geothermal equipment.”

The platform should automatically:

1. Understand the idea.
2. Identify the user's goal.
3. Extract requirements.
4. Identify users and roles.
5. Identify features.
6. Identify pages/screens.
7. Identify database requirements.
8. Identify APIs.
9. Identify technical requirements.
10. Identify design requirements.
11. Identify security requirements.
12. Identify testing requirements.
13. Generate a complete project architecture.
14. Generate an interactive mind map.
15. Let the user modify the mind map.
16. Let the user approve the plan.
17. Send approved tasks to specialized AI agents.
18. Use **Z.ai as the primary coding engine**.
19. Generate the actual project files.
20. Run the generated project.
21. Test it automatically.
22. Detect errors.
23. Send exact errors back to the coding AI.
24. Automatically fix them.
25. Test again.
26. Continue until the project passes defined quality checks.
27. Show a live preview.
28. Allow the user to edit the project using AI.
29. Allow version control and rollback.
30. Eventually deploy the project.

The user should feel that they are directing an intelligent development team rather than writing code manually.

# 17. AUTOMATIC BUILD + TEST + FIX LOOP

```text

   ↓

   ↓

   ↓

   ↓

   ↓
PASS? ───── YES → PREVIEW
   │
   NO
   ↓

   ↓
FIX
   ↓

```

Use a controlled retry limit.

```text

```

# 71. IMPLEMENTATION INSTRUCTION

Do not attempt to fake functionality with static UI.

If a feature is displayed, architect it so that it can become a real feature.

Do not use fake AI responses where actual API integration is intended.

Do not use fake testing results where real sandbox testing is intended.

Do not claim a project is working unless it has actually been built and tested.

Use mock/demo data only where backend functionality is not yet connected, and clearly structure the code so it can later be replaced by real services.

Build the system modularly so individual components can be upgraded without rewriting the entire platform.
